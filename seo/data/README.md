# Données Search Console

Alimenté chaque dimanche par `.github/workflows/seo-gsc-export.yml`. Ne pas éditer à la main.
`latest.json` est l'export courant ; les fichiers `gsc-AAAA-MM-JJ.json` sont l'historique.

Cette branche n'est jamais fusionnée dans `main` : c'est un cache de données lu par l'agent
SEO en début de cycle, pas du contenu.
